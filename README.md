## فارسی

پاک‌ساز ابزاری سریع و ساده برای مرتب‌کردن متن‌های فارسی در مرورگر است؛ به‌ویژه متن‌هایی که از هوش مصنوعی، وب یا منابع مختلف کپی شده‌اند و نویسه‌های پنهان، فاصله‌گذاری ناهماهنگ یا ترکیبی از حروف عربی و فارسی دارند.

### ✨ قابلیت‌ها

- حذف ایموجی‌ها و نشانه‌های شبیه ایموجی با یک قاعده‌ی اختیاری

- حذف نویسه‌های پنهان، کنترلی و صفرعرض
- حذف اعراب و کشیده‌ها
- تبدیل حروف عربی به معادل فارسی؛ برای نمونه: `ي ك ة` → `ی ک ه`
- یک‌دست‌کردن خط‌تیره‌ها، گیومه‌ها و فاصله‌گذاری
- تبدیل نشانه‌های رایج Markdown و نشانه‌گذاری فارسی
- تنظیم نیم‌فاصله و انتخاب ارقام فارسی، لاتین یا حفظ شکل اصلی آن‌ها
- سه الگوی آماده برای پاک‌سازی: سبک، استاندارد و کامل
- نمایش نویسه‌های پنهان پیش از پاک‌سازی
- گزارش تعداد تغییرات، تعداد واژه‌ها و نویسه‌ها و خروجی قابل کپی
- ذخیره‌ی خروجی در قالب فایل `.txt`
- رابط فارسی و انگلیسی با پشتیبانی کامل از راست‌به‌چپ
- پوسته‌ی روشن و تیره، طراحی واکنش‌گرا و پشتیبانی از `prefers-reduced-motion`

### 🚀 شروع سریع

```bash
git clone <your-repository-url>
cd paksaz
```

فایل `index.html` را مستقیماً در مرورگر باز کنید؛ نیازی به نصب بسته، ساخت پروژه یا اجرای سرور نیست.

### 🧭 روش استفاده

```text
Paste → Inspect → Tune rules → Clean → Copy / Save
  واردکردن متن  →  بررسی  →  تنظیم قواعد  →  پاک‌سازی  →  کپی یا ذخیره
```

برای پاک‌سازی سریع، پس از واردکردن متن کلیدهای `Ctrl/Cmd + Enter` را فشار دهید.

## English

Paksaz is a fast, minimal, browser-first **Persian text cleaning workbench**. It turns pasted text from AI tools, websites, and mixed Arabic/Persian sources into cleaner, more consistent content.

### ✨ Highlights

- Optional emoji and emoji-like symbol removal

- Removes invisible, directional, zero-width, diacritic and tatweel characters
- Normalizes Arabic letters into Persian equivalents
- Cleans dashes, curly quotes, Markdown markers and whitespace
- Converts punctuation to Persian forms when enabled
- Configurable ZWNJ and digit policies: Persian, Latin or unchanged
- Light, Standard and Full cleaning presets
- Visual hidden-character inspector
- Change report with character/word counters
- Copy result or download it as a `.txt` file
- Persian/English UI with RTL-first layout
- Responsive light/dark interface with reduced-motion support

### 🚀 Quick start

```bash
git clone <your-repository-url>
cd paksaz
```

Open `index.html` in any modern browser. No dependencies, build step or server required.

### 🛠️ Stack

`HTML` · `CSS Custom Properties` · `Vanilla JavaScript` · `Regular-expression text rules`
