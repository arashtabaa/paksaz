## فارسی

پاک‌ساز یک ابزار سریع، مینیمال و مرورگرمحور برای تمیزکردن متن‌های فارسی است؛ مخصوصاً متن‌هایی که از هوش مصنوعی، وب یا منابع مختلف کپی شده‌اند و نویسه‌های نامرئی، فاصله‌گذاری ناهماهنگ یا ترکیب حروف عربی و فارسی دارند.

### ✨ قابلیت‌ها

- پاک‌کردن نویسه‌های نامرئی، جهت‌دهی و صفرعرض
- حذف اعراب و کشیده‌ها
- تبدیل حروف عربی به معادل فارسی: `ي ك ة` → `ی ک ه`
- یکسان‌سازی خط‌تیره‌ها، گیومه‌ها و فاصله‌گذاری
- تبدیل نشانه‌های رایج Markdown و نقطه‌گذاری فارسی
- کنترل نیم‌فاصله و انتخاب ارقام فارسی، لاتین یا دست‌نخورده
- سه الگوی آماده‌ی پاک‌سازی: سبک، استاندارد و کامل
- بازرسی دیداری نویسه‌های پنهان پیش از پاک‌سازی
- گزارش تعداد تغییرات، شمارش واژه/نویسه و خروجی قابل کپی
- ذخیره‌ی خروجی به‌صورت فایل `.txt`
- رابط دو‌زبانه‌ی فارسی/انگلیسی با پشتیبانی کامل RTL
- تم روشن و تیره، طراحی واکنش‌گرا و پشتیبانی از `prefers-reduced-motion`

### 🚀 شروع سریع

```bash
git clone <your-repository-url>

```

فایل `index.html` را مستقیماً در مرورگر باز کنید؛ هیچ build step، نصب پکیج یا سروری لازم نیست.

### 🧭 مسیر استفاده

```text
Paste → Inspect → Tune rules → Clean → Copy / Save
  متن  →  بازرسی  →  تنظیم قاعده‌ها  →  پاک‌سازی  →  کپی / ذخیره
```

برای پاک‌سازی سریع، پس از واردکردن متن `Ctrl/Cmd + Enter` را بزنید.

## English

Paksaz is a fast, minimal, browser-first **Persian text cleaning workbench**. It turns pasted text from AI tools, websites, and mixed Arabic/Persian sources into cleaner, more consistent content.

### ✨ Highlights

- Removes invisible, directional, zero-width, diacritic and tatweel characters
- Normalizes Arabic letters into Persian equivalents
- Cleans dashes, curly quotes, Markdown markers and whitespace
- Converts punctuation to Persian forms when enabled
- Configurable ZWNJ and digit policies: Persian, Latin or unchanged
- Light, Standard and Full cleaning presets
- Visual hidden-character inspector
- Change report with character/word counters
- Copy result or download it as a `.txt` file
- Persian/English UI with RTL-first layout
- Responsive light/dark interface with reduced-motion support

### 🚀 Quick start

```bash
git clone <your-repository-url>
cd paksaz
```

Open `index.html` in any modern browser. No dependencies, build step or server required.

### 🛠️ Stack

`HTML` · `CSS Custom Properties` · `Vanilla JavaScript` · `Regular-expression text rules`
